# C++ Programming Lab Codes

A collection of C++ laboratory programs covering **classes, constructors, friend functions/classes, inheritance, inline functions, and basic application-oriented programs**.

## Topics Covered

### Object-Oriented Programming
- Classes and objects
- Default and parameterized constructors
- Friend functions
- Friend classes
- Copy constructors

### Inheritance
- Single inheritance
- Multilevel inheritance
- Multiple inheritance
- Hierarchical inheritance
- Hybrid inheritance

### Other C++ Concepts
- Inline functions
- Basic console programs
- Application-oriented examples such as billing, banking, and patient records

## Compiling and Running

Using g++:

```bash
g++ hello_world.cpp -o hello_world
./hello_world
```

For another program, replace the source filename and output name.

On Windows PowerShell, the executable can be run with:

```powershell
.\hello_world.exe
```

## Purpose

These programs are intended for C++ laboratory practice and demonstrate core object-oriented programming concepts in small, easy-to-study examples.
